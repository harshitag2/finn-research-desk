# Mobile workspace

FINN prioritizes phone screens at widths up to 780 CSS pixels. Five persistent tabs expose Home, Research, Portfolio, Markets and More. More opens an accessible dialog with terminal, documents, inbox, management/cash, analysis, theses, saved notes and preferences. The selected tab is announced with aria-current and navigation closes the tools sheet.

The phone layout includes safe-area bottom spacing, 54px navigation targets, a sticky search header, 16px form inputs, company/document cards, filing cards, collapsible research scope, and bottom-sheet dialogs. Long research results retain citations and source inspection. The detailed terminal board scrolls within its own container with a sticky security column. Desktop retains full navigation and tables.

A web manifest and Apple home-screen metadata request standalone display where supported. This does not add offline financial-data caching, native push, or an app-store package. Website access restrictions continue to apply.

Browser verification covers phone widths of 390px and 320px, navigation, More-sheet selection/closing, company documents, research scope, portfolio/markets and the terminal's contained horizontal scroll. The automated application suite remains the regression check for the existing research and extraction paths.
