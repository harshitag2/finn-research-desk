# FINN 0.12.0 — management, cash and change monitoring

## Delivered workflows

- Management commitments: extract dated explicit numerical commitments and achieved results, preserve revisions and compare only compatible metric, fiscal period, accounting basis and unit. Ranges and accounting negatives are parsed separately. A missing disclosure or incompatible adjusted/unadjusted measure is not graded.
- Cash and capital allocation: annual primary-source PAT, CFO, capex and related amounts with deterministic free-cash-flow/cash-conversion formulas. Physical-page expansion retains statement headers and currency scales. Conflicting values remain available with quotes but no single amount or dependent ratio is silently chosen. Banks/financials receive a sector-specific limitation rather than an industrial template.
- Change inbox: persistent D1 configuration, exact saved thesis version, relevance explanations, configurable price/volume limits, deduplicated events, Watch/Dismiss/Restore and recorded scan status. Exposure is displayed only from actual imported snapshot weights. Local preference/thesis changes sync an already configured personal monitor.
- Unfamiliar-company setup: discover primary disclosures, select and index a verified PDF, retain page/date/period/checksum provenance, and continue research. The server validates source identity, redirects, size/type and allowed hosts; arbitrary URL fetching is not exposed. Indexed documents remain in the current browser.
- Management background: read the actual management-change filing, separate incoming/outgoing people and preserve effective date, exact source quote and physical page. No unverified replacement or career history is invented. Short biography annexures retain continuation pages.
- Background source scan: linked hourly cloud task in Asia/Kolkata, using the published private monitor endpoint and persistent readback. A configured personal monitor can be paused; source failures are recorded and the last successful checkpoint retained. The app inbox is the delivery surface; email/SMS/mobile OS push are not configured.

## Known limits

Source/provider availability varies. Numerical quote validation is not full semantic entailment. Model schema400 responses may retry once in JSON mode; all extraction guards still apply. Caches are bounded and isolate-local. The monitor retains up to150 latest items per read, uses public-source polling rather than exchange streaming, and does not send trade orders. Automatic source discovery is followed by a user-selected import; it does not silently ingest arbitrary URLs.
